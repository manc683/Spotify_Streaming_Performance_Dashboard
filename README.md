## 🎵 Spotify Artist Streaming Performance Dashboard

📌 Project Overview

The **Spotify Artist Streaming Performance Dashboard** is an interactive Excel dashboard designed to analyze artist streaming performance and identify important trends in Spotify music data.

The dashboard allows users to explore streaming performance using different filters and visualizations.

## 🎯 Objectives

- Analyze artist streaming performance.
- Identify top artists based on total streams.
- Compare streaming performance across countries and genres.
- Analyze collaboration performance among artists.
- Compare streams of lead and featured artists.
- Understand performance trends using different artist categories and filters.

## 🛠️ Tools & Technologies

- Microsoft Excel
- Pivot Tables
- Excel Charts
- Data Cleaning
- Data Analysis
- Interactive Filters / Slicers

## 📊 Dashboard Features

The dashboard includes:

- **Total Number of Artists**
- **Total Streams**
- **Top Artist**
- **Solo Performance Rate**
- **Collaboration Rate**
- **Average Streams**
- **Top 5 Artists by Streams**
- **Top 5 Countries by Streams**
- **Total Streams by Genre**
- **Collaboration Rate by Top 5 Artists**
- **Lead vs Featured Artist Streams**

## 🔍 Interactive Filters

Users can filter the dashboard based on:

- Gender
- Artist Type
- Debut Year Group
- Performance Category

These filters make it easier to explore different segments of the dataset.

## 📈 Key Analysis

The dashboard helps answer questions such as:

- Which artists have the highest number of streams?
- Which countries contribute the most streams?
- Which genres have higher streaming activity?
- How does collaboration affect artist performance?
- How do lead and featured artist streams compare?
- How does streaming performance vary across different artist groups?
